# FE3L — como rodar o site

1. Instale o Node.js (versão LTS): https://nodejs.org
2. Abra esta pasta no VS Code (Arquivo > Abrir Pasta)
3. Abra o terminal do VS Code (Ctrl + ')
4. Rode: npm install
5. Rode: npm run dev
6. Abra no navegador o endereço mostrado no terminal (normalmente http://localhost:3000)

Para gerar a versão de produção: npm run build
